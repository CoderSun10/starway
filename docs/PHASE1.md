# 星程 Starway · 一期说明

对应仓库：<https://github.com/CoderSun10/starway>

## 产品一句话

自己用的桌面日程与花销工具。日历看一天，**时间**管专注，**用度**管预算和记账。不做账号。

## 已交付

### 桌面端（`ningshi-pc/`）

- Electron 无边框圆角窗口、自定义标题栏、托盘、开机自启
- 侧栏：日历 / 时间（计时·计划·统计）/ 用度（记账·账本·统计）/ 设置
- 日历普通模式：格子分钟带 `′`；右侧当日计划 + 当日成果；去专注只跳转不计时
- 日历热力图：时间 / 用度切换；格子大小与普通模式一致，仅平移居中
- 计时页一屏展示；统计柱状图平均线（Y 轴刻度列标红字，避开刻度重叠）
- 记账记录填写时间；改/删为图标
- 设置里可改本机 API 地址（换服务器用）

### 后端（`backend/`）

- Express + MySQL 8
- 计划 / 任务 / 番茄会话 / 预算时段 / 支出
- 启动时 `sql/migrations/` 增量迁移
- 演示数据脚本 `scripts/load-demo.js`
