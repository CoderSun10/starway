# 凝时 · 后端测试说明

## 测什么

| 类型 | 目录 | 内容 |
|------|------|------|
| **单元测试** | `tests/unit/` | 跨天时长、北京日历日归属、计划日重叠、任务校验、计时墙钟 |
| **集成测试** | `tests/integration/` | 真实 Express + MySQL：建跨天计划、会话、统计 |

## 跨天规则（与产品一致）

1. **时长**：按绝对时间差（分钟），跨不跨日历日结果一样。  
   例：北京 23:00→次日 01:00 = **120 分钟**。
2. **会话统计归属**：按 **`started_at` 的北京日历日** 整段计入，**不拆到两天**。  
   例：23:30 开始、做 90 分钟 → 只算在「开始那天」。
3. **计划列表按日筛选**：计划时间段与该日有**交集**即显示（跨天计划两天都能看到）。

## 怎么跑

```bash
# MySQL 需已启动（docker compose up -d）
cd backend
npm install
npm test                 # 全部
npm run test:unit        # 仅单元（不依赖业务数据）
npm run test:integration # 仅集成（写库，带【测试】前缀，结束后清理）
```

集成测试会插入带 `【测试】` 前缀的数据，并在 `afterAll` 删除。
